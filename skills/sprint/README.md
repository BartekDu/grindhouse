# /sprint — scope-bound delivery on the grind engine

The third grind-engine mode:

```
GRIND ENGINE (scripts/grind/* law, .claude/grind/ state, 5h windows, audit chain)
 ├ /grind       burn mode — fill the window, stop at the quota floor
 ├ /semi-grind  supervised standardization — quiz-gated taste forks
 └ /sprint      scope-bound delivery — stops when the task is DONE
```

Pipeline: **clarity gate → founder quiz (if vague) → high-effort plan + mandatory
codex pass → team manifest (models matched to difficulty) → waves as Workflow
runs (builders in worktrees) → window chaining → DONE = STOP.**

- Shares the guardrail library verbatim with `/grind` (canonical copy:
  `F:\code\Underline\scripts\grind\`; global mirror here in
  `~/.claude/skills/grind/scripts/grind/`). Never fork a script.
- The hooks key off `.claude/grind/.active`, not the skill name — same state
  tree, same campaign-branch convention (`grind-DD-MM-YYYY`).
- `/soft-pause` pauses a sprint gracefully (quota-gate exit 7, savepoint drain).
- Sibling docs: `~/.claude/skills/{grind,semi-grind,soft-pause,culture}/`.

Born 2026-07-10 from the grind-engine-v2 plan (Underline PR #117 carries the
script-law upgrades).
